# 01 LIMUC Benchmark

## Question

Does the proposed loss improve LIMUC ulcerative-colitis severity scoring under
the published LIMUC benchmark convention?

This is the paper-facing E01 experiment. FOROH mechanism ablations that used to
occupy E01 now live under:

```text
Experiment/FOROH_Ablation/01_Coordinate_Necessity/
```

## Dataset

- Dataset: LIMUC.
- Train/validation pool: 9,590 images from 479 patients.
- Held-out test set: 1,686 images from 85 patients.
- Use the fixed official fold files in:

```text
Dataset/LIMUC/cross_validation_folds_train_val_info/
```

No split seed is part of this experiment. The folds are fixed input artifacts,
not generated by the training code.

Raw image folders remain local and ignored by Git:

```text
Dataset/LIMUC/patient_based_classified_images/
Dataset/LIMUC/train_and_validation_sets/
Dataset/LIMUC/test_set/
```

## Backbones

Minimum benchmark set:

- Inception-v3: direct comparison to the CDW-CE lineage.
- CoAtNet_2: strong published LIMUC backbone.
- ResNet-18 or MobileNet-v3-large: lightweight-control backbone.

## Losses

Required comparisons for each backbone:

- CE.
- CDW-CE.
- Ours.

CDW-CE must report alpha `1..10`. If Ours has comparable hyperparameters, they
must receive an explicit sweep at the same level of care.

## Code


CLI exposes only two options:

```bash

python Experiment/01_LIMUC_Benchmark/train.py --backbone resnet18 --loss foroh
```

Each command runs all 10 fixed folds for one backbone/loss pair.

## Training Protocol

- Input resolution: 224 x 224.
- Pretraining: ImageNet-1K.
- Epochs: 200 unless reproducing a baseline requires a documented exception.
- Augmentation, optimizer, scheduler, and backbone settings are fixed across
  losses within each backbone.
- Training RNG seed: 42.
- Fold assignment: fixed by the official fold JSON files. Do not regenerate
  folds and do not introduce a split seed.
- Test-set model selection is forbidden.

## Metrics

Primary:

- QWK.

Required secondary metrics:

- Accuracy.
- Macro-F1.
- MAE.
- Per-class recall or per-class F1.
- Remission classification for Mayo 0/1 vs 2/3: Kappa and F1.

Required analyses:

- Confusion matrix.
- Mayo 2 and Mayo 3 minority-class behavior.
- One-vs-rest ROC/AUC and macro-average AUC.
- Wilcoxon signed-rank test over fold-level results.
